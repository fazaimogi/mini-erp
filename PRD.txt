**Version:** 1.0

**Backend:** Go + Gin

---

## 1. Product Overview

### 1.1 Product Name

**ERP Mini System**

### 1.2 Description

ERP Mini System adalah aplikasi web untuk membantu perusahaan mengelola aktivitas operasional dasar dalam satu sistem terintegrasi.

Sistem berfokus pada:

* Product Management
* Inventory Management
* Customer Management
* Sales Management
* User Management
* Dashboard & Reporting

Aplikasi menggunakan arsitektur **separated frontend dan backend**, dengan Next.js sebagai frontend dan Go sebagai REST API backend.

### 1.3 Problem Statement

Perusahaan kecil dan menengah sering menggunakan spreadsheet atau sistem terpisah untuk mengelola:

* Data produk
* Data stok
* Data pelanggan
* Transaksi penjualan

Pendekatan tersebut dapat menyebabkan:

* Data sulit dipantau secara real-time
* Ketidaksesuaian data stok
* Pencatatan transaksi manual
* Kesulitan melihat performa penjualan
* Tidak adanya kontrol akses pengguna

ERP Mini System dibuat untuk menyediakan sistem terintegrasi yang menangani proses tersebut.

# 14. Sales Business Rules

## 14.1 Stock Validation

Sistem harus memastikan stock mencukupi sebelum transaksi dibuat.

```text
IF requested_quantity > current_stock
THEN reject transaction
```

Error:

```text
INSUFFICIENT_STOCK
```

## 14.2 Automatic Stock Deduction

Jika transaksi berhasil:

```text
new_stock = current_stock - quantity
```

## 14.3 Database Transaction

Sales harus menggunakan database transaction.

```sql
BEGIN;

CREATE SALE;

CREATE SALE ITEMS;

UPDATE INVENTORY;

CREATE INVENTORY TRANSACTION;

COMMIT;
```

Jika salah satu proses gagal:

```sql
ROLLBACK;
```

Tujuannya menjaga konsistensi data.
